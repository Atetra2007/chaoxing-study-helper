# 0.4.0 指定目录保存验证

日期：2026-10-14。

## 实现与交付

- 用户批准后实现“选择文件夹＋按课程整理/直接存入”。本机已有目标目录为 `所选目录/课程文件`；本轮未修改其中已有资料。
- 顶层扩展小窗口负责原生目录选择与重新授权，目录句柄保存在扩展自身 IndexedDB。小窗、后台消息仅传递目录记录 ID、名称与权限状态。
- 任务启动时固定目录与相对路径。原文件和生成的 PDF 均可使用指定目录；PDF 继续先在 OPFS 按页生成，保持已有完整性规则。
- 按 1 MiB 分块写入，关闭目标文件后读回字节数和 SHA-256，匹配才显示“已保存并校验”。目录保存使用独立回执，不伪造浏览器下载 ID。
- 已有同名文件采用编号副本；扩展内部任务通过 Web Lock 排队分配名称。浏览器没有原子的“仅创建不存在文件”接口，外部程序同时创建同名文件的极小竞争窗口不在扩展锁保护内。
- 关闭课程分组后直接保存到所选文件夹，不增加“学习通课件”层；本次另存为不会改变默认目录。目录模式不显示无法实现的“打开所在文件夹”。
- 设置页使用独立滚动内容区，页签、“完成”和版本/自动保存提示保持可见。
