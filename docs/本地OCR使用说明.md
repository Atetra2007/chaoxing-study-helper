# 本地OCR文字优先模式（0.1.5试验功能）

勾选助手中的“文字优先”后，本机组件先分析每一页。可信的纯文字页生成真正的文字PDF页，按原来的文字框位置排列；插图、表格、公式、复杂分栏、旋转文字、低可信文字或未覆盖内容的页面保留整页图片，不逐页询问。页数与顺序保持不变。

这不是逐像素还原字体的功能。文字位置和页面比例尽量保持，字体暂用Windows宋体；OCR仍可能识别错误，请核对原文。水印会影响识别，当前物理教材的小样本因此大多回退图片，不能承诺整本教材显著缩小。

## 本机使用

当前电脑已经在项目 `work/ocr-runtime` 安装独立Python环境，模型放在 `work/ocr-models`，不影响扩展普通保存。

1. 在项目目录运行 `powershell -File scripts/start-ocr.ps1`。服务仅监听 `127.0.0.1:8765`，后台运行；就绪信息在 `work/ocr-service.log`。
2. 在Edge重新加载0.1.5扩展，关闭旧助手页，从课件重新打开助手。
3. 勾选“文字优先”，点击“连接本地OCR”。首次由浏览器询问是否允许访问本机组件。
4. 在出现的文件选择控件中选择 `D:\projects\chaoxing\work\ocr-connection.json`，等到显示“本地OCR已连接”。该文件是本机连接凭据，不要上传或发给别人；内容不进入诊断。
5. 选择图片页画质后保存。结果显示“文字页 / 图片页”数量。若都是图片页，说明本次没有页面满足文字转换条件，并不代表OCR文字版已生成。

选择连接文件后，文件控件会自动清空并显示“未选择文件”。请以下方“本地OCR已连接”提示为准；看到该提示即可保存，无需反复选择。直接在资源管理器中双击连接文件不会连接助手。

组件重启会更换连接凭据，需要重新选择连接文件。助手关闭后不记住凭据。取消保存会停止后续页；已送入本地模型的单页推理可能还需短暂结束。组件断开或超时会明确停止保存，可重新连接重试，或取消文字优先保存图片版。

不用OCR时可运行 `powershell -File scripts/stop-ocr.ps1` 停止本项目组件；脚本会核对进程身份，普通图片保存不受影响。

首次在另一台Windows电脑使用，需要Python 3.12，在项目目录运行 `powershell -File scripts/setup-ocr.ps1 -Python <Python路径>`。依赖版本锁定在 `local_ocr/requirements-lock.txt`。首次准备会从官方模型发布渠道下载模型，随后识别在本机完成，不向云端发送课件。此组件暂未适配Mac。

## 验证边界

- 本地真实模型、客户端和PDF合并已打通：程序生成的中文纯文字样本转换后可选中文字，提取文字与已知内容完全一致，页面没有整页图片；排版已渲染检查。
- 真实教材公式、图表和不确定页自动回退，原画质模式下回退页逐像素一致。4页混合样本保留页数与顺序。
- 用户已提供真实Edge中“本地OCR已连接”的截图并反馈使用成功；本次生成文件尚未独立核验，完整教材的文字页比例与逐页准确性仍待验证，也没有证明所有纯文字真实教材页均可转换。
- 高置信度不等于没有错字，公式检测也不是绝对可靠，因此本功能默认关闭并标为试验。

技术依据：PaddleOCR官方[版面分析说明](https://www.paddleocr.ai/main/en/version3.x/pipeline_usage/PP-StructureV3.html)列出了文字、图像、表格和公式等类别。本项目仅使用本地版面检测和OCR模块，不调用云端API，也不将公式转写为新公式。
