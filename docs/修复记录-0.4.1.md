## 已复现缺口

1. 用当前 `panel.js` 配旧 `model.js`，模块链接报缺少 `directoryRelativePath`；用当前脚本配旧 HTML，绑定新增按钮时找不到节点。两者都在 `panel-ready` 之前中断，留下外层超时提示。
2. 旧后台转发就绪通知会吞掉 `tabs.sendMessage` 的失败，并向面板返回成功；缺接收器或空应答都可能被误认为送达。面板只发送一次通知。
3. 以上是本地复现的具体兼容/时序缺口。无法直接读取实际扩展 iframe 的加载错误，尚未唯一确定此次实机命中哪一条；不把推测当作实机根因。

## 修复

- 构建时为第一方静态模块引用及 HTML 本地脚本、样式增加当前版本参数，隔离更新前后的缓存键。构建与安装源码核对使用同一转换，旧构建不能冒充新版本。
- 使用无静态依赖的 `panel-loader.js` 加载主面板，捕获模块链接/启动异常；显示简洁的恢复提示和“重新加载界面”，不暴露原始异常或资源地址。加载较慢时保留 DOM，允许迟到的正常初始化恢复。
- 面板就绪最多尝试 3 次；后台只有收到页面接收器对当前视图标识的实际确认才返回成功。旧视图标识拒绝确认，保留迟到就绪恢复能力。
- 目录功能、来源隔离、闭合 Shadow DOM 及保存任务生命周期保持原有规则。没有新增浏览器权限。
