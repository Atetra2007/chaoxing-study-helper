## 实现范围

- 原课件页内的拖动小窗与贴边入口，收起后保留任务和进度，工具栏图标不再新开助手标签页。
- 默认直接保存当前课件；多份内容才显示选择器。课程、文件名称、画质、OCR和保存位置集中在设置中。
- 独立offscreen任务宿主复用OPFS、逐页PDF写入和既有完整性逻辑；后台仅接受受信扩展来源并将任务绑定到当前标签页。
- 不通过网页消息传递保存指令，快照不泄露资源链接或OCR凭据；扫描排除助手自身的节点、标题、页数和iframe。
- 不覆盖旧资料。刷新、导航、关闭来源标签页停止任务；不支持浏览器重启后的续传。
