# 学习通课件助手 0.4.3：安装使用说明

## 下载试用版

当前版本为 **0.4.3公开试用版**，目标环境为Windows + Edge 116及以上，建议使用最新版Edge。普通保存不需要安装Python、Node.js或本机OCR服务。

1. 打开[0.4.3版本发布页](https://github.com/Atetra2007/chaoxing-study-helper/releases/tag/v0.4.3)。
2. 在 **Assets** 中点击 **`chaoxing-study-helper-0.4.3-edge.zip`**。
3. 在资源管理器中右键ZIP →“全部解压”，将文件保存在一个固定目录。
4. 找到解压后直接包含 `manifest.json` 的文件夹，按下方“首次安装”加载。

不要选择 `Source code (zip)`：那是开发源码，缺少构建时打包的依赖。`promo.zip` 是推广素材，也不是安装包。下载不完整时可重新下载；SHA-256校验值随版本提供。

本版支持页内助手、独立小窗后备入口和指定目录保存，验证边界见文末。试用建议先保存一份短课件，再核对实际PDF的总页数、顺序和清晰度。

## 更新已有扩展

下载新版ZIP后，先解压到临时目录；**备份原扩展文件夹**，然后把新版文件复制到原扩展文件夹并替换对应程序文件。保留原文件夹的位置，不必卸载扩展。不要把课件或笔记存进扩展程序文件夹。

接着完成以下操作：

1. 在 Edge 地址栏输入 `edge://extensions`，找到“学习通课件助手”，点击卡片上的刷新/重新加载按钮。
2. 关闭旧独立小窗，刷新原课件页，重新打开助手。
3. 若提示“助手暂未加载完成”，点击“独立小窗打开”，确认出现“课件 / 设置”，底部显示 `v0.4.3`。
4. 核对保存位置后再使用；若目录权限失效，按提示重新授权。

下面的命令行方式仅适用于克隆源码进行开发的人，普通用户无需执行。

### 开发者更新方式

推荐在项目目录运行 `pnpm update:local`：自动构建、检查版本和源码一致性，备份旧文件，再逐项校验更新文件。首次默认安装目录为 `outputs/installed`；已安装用户首次指定 `pnpm update:local --target outputs/原安装目录名`，此后自动记住该目录，不改变Edge加载路径。目标仅允许本项目outputs的直接子目录，不接受其他扩展目录或链接目录。

旧文件备份保存在 `work/extension-backups/`，具体路径由命令输出。需要恢复时，将该次备份中的文件复制回原安装目录，再重新加载扩展；不要删除已有课件或批注。更新文件不会自动替你重新加载Edge。

更新已安装扩展时，将新构建目录中的文件复制到原安装目录，保留原目录位置。然后：

1. 在 Edge 手动打开 `edge://extensions`，找到“学习通课件助手”，点击卡片上的刷新/重新加载按钮。
2. 关闭原来的独立助手页面，刷新原课件页，点击页面右侧“课件助手”或工具栏扩展图标。
3. 若仍显示“助手暂未加载完成”，点击“独立小窗打开”。确认出现“课件 / 设置”，底部显示 `v0.4.3`。
4. 在“设置”选择“指定文件夹”，选择桌面的“课程文件”并授权；返回“课件”，核对名称和位置后点击保存。

无需卸载或再次加载目录。0.2.0增加offscreen权限，使文件生成在扩展内部继续运行；网站域名范围不变。启用本机OCR时单独申请访问本机组件的可选权限。旧安装目录的名称可以保留，实际版本以小窗和manifest为准。

## 首次安装

1. 在 Edge 地址栏中手动输入 `edge://extensions`，按回车。
2. 打开“开发人员模式”（不同版本可能称“开发者模式”）。
3. 点击“加载解压缩的扩展”。
4. 选择直接包含 `manifest.json` 的固定安装目录，例如运行更新脚本后的 `outputs/installed`。
5. 确认扩展列表中出现“学习通课件助手 0.4.3”。

请选择直接包含 `manifest.json` 的目录，而不是项目根目录或 ZIP 文件。

如果在其他电脑使用，先把 ZIP 解压到一个固定目录，再按以上步骤加载其中包含 `manifest.json` 的文件夹。加载后不要移动该文件夹。

## 使用

1. 在 Edge 正常登录学习通，打开需要保存的 PPT/PDF 课件，等待页面显示。
2. 点击工具栏的扩展菜单，选择“学习通课件助手”。可以将它固定到工具栏方便下次使用。
3. 助手在原页面展开小窗，自动识别当前课件；页面右侧贴边入口也能打开同一小窗。如果加载超时，点击“独立小窗打开”，继续在单独的小窗口中操作。
4. 如果识别出多份内容，先选择要保存的一份。可见的原文件链接会优先列出。
5. 在“课件”页核对课件名、页数和“保存到”，点击“保存 PDF”或“保存原文件”。需要调整时打开“设置”页签；常用偏好自动记忆，连接凭据不保存到网页或偏好中。
6. 指定文件夹保存时，等待“已保存并校验”，按小窗显示的目录和实际文件名查找；浏览器下载时，等待“浏览器已确认下载完成”，再点击“打开所在文件夹”。

拖动小窗标题栏调整位置；点击右上角“−”收起，贴边入口继续显示进度，再次展开不会重新保存。标题栏可用方向键移动。小窗不再显示逐页格和诊断信息。

独立小窗始终对应发起它的原课件页。重复点击入口会聚焦同一窗口；关闭独立小窗不会取消正在保存的任务，需要停止时点击“取消保存”。请保留原课件页，刷新或关闭它会停止任务。重新打开独立小窗可查看同一任务的状态，不会因此再次保存。

## 选择保存位置

需要固定保存到自己的文件夹时，按以下步骤设置一次：

1. 在小窗打开“设置”，将“保存位置”选为“指定文件夹”，点击“选择文件夹”。
2. 助手会打开一个目录授权标签页，点击其中的“选择文件夹”，通过浏览器的系统选择器选定目录，例如桌面上的“课程文件”，并允许保存。
3. 看到“文件夹已设置好”后点击“返回课件助手”，确认小窗中的文件夹名称和“已授权”。授权页保持打开，不会自动关闭。以后在“课件”页直接点击保存即可，不必每次重新选择。助手不会修改Edge的默认下载位置。

“按课程分文件夹”默认开启。假设所选根目录是“课程文件”，路径为：

| 保存方式 | 输出位置示例 |
| --- | --- |
| 指定文件夹，开启课程分组 | `课程文件/概率论/第一章.pdf` |
| 指定文件夹，关闭课程分组 | `课程文件/第一章.pdf` |
| 浏览器下载文件夹，开启课程分组 | `浏览器下载目录/学习通课件/概率论/第一章.pdf` |
| 浏览器下载文件夹，关闭课程分组 | `浏览器下载目录/学习通课件/第一章.pdf` |

已识别课程的文件夹名称分别记忆，切换课程不会沿用上次课程名。指定目录且开启分组时，无法确认课程会要求填写“课程文件夹”或关闭分组；浏览器下载方式仍可使用“未分类课程”。当前文件名只作用于这份课件。同名文件会自动另存副本；指定目录保存后，小窗显示实际名称，浏览器下载后的实际名称以下载列表为准。

还可选择“每次选择保存位置”，每次使用浏览器原生保存对话框。只想临时换位置时，点击“课件”页的“本次另存为”：这一次通过浏览器对话框选择文件位置，默认目录和课程偏好保持不变。对话框里的位置为实际保存位置，小窗提供的路径仅为建议。

文件夹权限由浏览器管理，重启或权限变化后可能需要重新授权。在小窗点击“重新授权文件夹”，或进入“设置”点击“重新授权”，再在授权页点击“继续使用这个文件夹”并允许访问。目录已移动或不可用时，选择其他文件夹；授权取消或失败不会自动改存到别处。

指定目录保存时，助手写入后会重新读取文件，核对大小和内容校验值，通过后才显示“已保存并校验”。这条路线不提供“打开所在文件夹”按钮，请在所选目录中查看；浏览器下载方式继续提供该按钮。助手只展示目录名称与相对路径，不猜测磁盘绝对路径。

通过助手点击“保存原文件”也遵循上述保存位置。直接点击学习通网站原有的打开或下载链接，则由网站和浏览器处理，不受助手目录设置控制。

## 保存进度

“图片页画质”默认均衡压缩，保留来源分辨率与颜色；精细公式或需要保留来源像素时选择“原画质”。已有JPEG不重复有损压缩，无法有效缩小的页面保留来源图片。压缩比例因教材而异。

“文字优先（本机OCR · 试验）”默认关闭。勾选后，可信纯文字页尽量按原位置生成文字；插图、表格、公式及不确定页自动保留图片。需要先连接本机组件，具体步骤见[本地OCR使用说明](本地OCR使用说明.md)。当前电脑已安装组件，但新版扩展首次授权和连接仍需手动操作。

“页数依据”区分阅读器明确显示的总页数与已适配阅读器列出的页面。后者可以保存列出的页面，但仍显示“整份完整性未确认”；浏览器下载完成或目录写入校验通过，都不自动证明网站已提供整份课件。

同类失败合并显示简短原因和对应操作。缺页时显示失败数量并提供补存；课件变化时要求重新识别。内部仍保留脱敏排错数据与逐页校验，但不占日常界面。

只要还有失败页，工具就不会把不完整的资料保存为完整PDF。“重试失败页面”会保留成功页，只补存失败页。

点击暂停后，已经发出的请求会完成；后续请求停止。点击继续可恢复。暂停适用于图片获取阶段，PDF合并、原文件获取和目录写入阶段可以取消。目录保存取消时，已经写完的文件会保留；若尚未完成读回校验，界面不会把它标记为保存成功。

保存时可以收起小窗、切换标签页或窗口，只需保留原课件页。勿在原标签页切换到另一份课件。刷新、导航、关闭原课件会停止任务；电脑休眠会暂停工作。重启浏览器、扩展重新加载或后台任务文档意外退出后需重新识别，不承诺跨重启恢复。

## 权限与本地数据

- `activeTab`、`scripting`：在用户发起操作时读取课件页面及嵌套阅读器。
- `https://*.chaoxing.com/*`：读取学习通课程页面和文档阅读器。
- `https://*.cldisk.com/*`：获取当前课件引用的页面图片或文件。
- `downloads`：保存文件并确认浏览器下载完成，支持打开所在文件夹。
- `storage`：在本机记住课程名称、画质等偏好、小窗位置与最近60条保存记录。
- `offscreen`：小窗收起后在扩展内部继续生成文件，并保留暂停/失败补存状态。

指定文件夹的访问权限由系统选择器单独确认。目录访问凭据保存在当前浏览器配置的扩展私有数据库中，网页只接收目录名称等显示信息；助手只向用户选定目录及所需课程子目录保存文件。此设置不会自动同步到其他电脑或浏览器配置。

不需要输入密码，不读取Cookie内容，不上传课件到第三方处理服务。依赖的PDF库已打包，不在线加载脚本。

保存图片PDF时，来源图片和生成中的PDF暂存在浏览器私有本机存储。内存只处理当前页；暂存不会上传。成功、取消或重新识别后清理；失败时保留来源供同一任务补存。异常关闭遗留的数据会在下次保存时清理，不能跨重启续存。磁盘空间需要同时容纳来源、输出及浏览器的临时写入文件。

## 常见问题

**小窗一直显示“助手暂未加载完成”**：更新到0.4.3后，在Edge扩展管理页重新加载助手并刷新原课件页；若仍超时，点击“独立小窗打开”。看到“课件 / 设置”后，选择保存目录并保存即可。独立窗口若显示加载失败，按窗口内的“重新加载界面”提示处理；若仍失败，反馈该窗口的提示文字即可，不需要反复尝试F12排查。重新加载扩展或刷新原课件会停止现有任务，请先等保存结束。

**旧版小窗出现但无法识别，提示未分类错误**：更新到0.4.3，在Edge扩展管理页重新加载助手，再刷新原课件页并重新打开资料。仅点击旧页面的“重新识别”不会更新已加载的扩展代码。0.2.1起的后台启动修复继续保留，连接失败提供重新识别或重新加载建议。

**独立小窗提示原课件已变化或连接失效**：回到原课件页重新打开助手，再从该页进入独立小窗。窗口不会自动改为控制其他标签页。

**没有识别到课件**：确认打开的是具体文档阅读器，等待加载后点击“重新识别”；确认扩展有访问学习通的权限。当前版本对未知阅读器会停止并提示，不猜测未显示的总页数。

**课程“资料”里的WPS教材**：保持教材弹窗打开，从同一个课程标签页点击助手。对于已验证的页面，助手会在需要时切换到教材自带的普通预览，并使用教材文件名。若提示普通预览未加载，点击教材右下角的预览切换按钮，等待页面出现后回助手重新识别。只有WPS画布且没有可用普通预览的资料仍暂不支持。

**提示本机临时存储不可用或空间不足**：腾出浏览器所在磁盘空间后重试。保留原课件页可在同一任务中补存，小窗可以收起；若浏览器不支持临时存储，请使用新版Edge。工具不会回退到整本教材占用内存的旧路线。

**某些页失败**：检查网络后重试。若显示访问被拒绝，回学习通恢复登录并重新打开资料，再点击“重新识别”。

**原文件入口失败**：只支持页面可见且指向支持格式的正常链接。需要跳转的下载入口、特殊响应或未支持的域名可能暂不可用；可以选择同一份资料的页面PDF（若已识别）。

**PDF不能选择文字**：普通图片页可以批注，但不能选择文字。文字优先模式中，只有成功转换的文字页可选中文字；识别不确定而保留的图片页仍不可选择。原始可编辑PPT和矢量图不会从图片中恢复出来。

**保存完成但没有在预期文件夹中找到**：指定目录保存时，核对小窗显示的根目录名称、课程子目录及实际文件名，重名文件可能带编号；它不出现在浏览器下载列表中。浏览器下载或“本次另存为”可从下载列表查看实际位置，以对话框手动选择的位置为准。

**提示目录需要授权或写入失败**：先按提示重新授权或选择有效目录；磁盘空间不足时腾出空间后重试。同一任务保留已获取的图片页供重试，不会静默切换到浏览器下载。如果只想先保存这一份，可主动选择“本次另存为”。
