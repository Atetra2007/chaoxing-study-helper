# 学习通课件助手 0.4.3：下载与安装

正式版0.4.3支持Windows上的Google Chrome与Microsoft Edge。安装包统一为 **`chaoxing-study-helper-0.4.3.zip`**：

| 浏览器 | 当前状态 | 建议 |
| --- | --- | --- |
| Google Chrome | 支持 | 使用最新版，最低版本要求116 |
| Microsoft Edge | 支持 | 使用最新版，最低版本要求116 |

普通保存无需Python、Node.js或本机OCR服务。以下步骤适用于同一份完整安装包；Edge与Chrome需要分别安装、登录学习通和设置保存目录。

## 1. 下载并解压

1. 点击[直接下载安装包](https://github.com/Atetra2007/chaoxing-study-helper/releases/download/v0.4.3/chaoxing-study-helper-0.4.3.zip)，或打开[0.4.3发布页](https://github.com/Atetra2007/chaoxing-study-helper/releases/tag/v0.4.3)，在 **Assets** 中选择 **`chaoxing-study-helper-0.4.3.zip`**。
2. 在资源管理器中右键ZIP → **全部解压**，解压到一个固定文件夹。
3. 打开解压后的文件夹，找到直接包含 `manifest.json` 的那一层。安装时选择这一层，不要选择ZIP文件或外层空目录。

不要下载 `Source code (zip)` 作为安装包：它是开发源码，缺少构建时打包的依赖。`promo.zip` 是推广素材，也不是安装包。[SHA-256校验清单](https://github.com/Atetra2007/chaoxing-study-helper/releases/download/v0.4.3/SHA256SUMS.txt)可用于核对下载完整性。

## 2. 在浏览器中加载

按你使用的浏览器操作：

| 操作 | Edge | Chrome |
| --- | --- | --- |
| 在地址栏输入并回车 | `edge://extensions` | `chrome://extensions` |
| 开启开关 | 开发人员模式 | 开发者模式 |
| 点击加载按钮 | 加载解压缩的扩展 | 加载已解压的扩展程序 |
| 选择文件夹 | 直接包含 `manifest.json` 的文件夹 | 同一完整构建中直接包含 `manifest.json` 的文件夹 |

按钮名称可能随浏览器版本略有不同。加载完成后，应看到 **学习通课件助手 0.4.3**。

点击浏览器工具栏的扩展菜单，将“学习通课件助手”固定到工具栏，方便以后打开。加载后不要移动或删除扩展程序文件夹，也不要把课件和笔记放在里面。

首次使用建议先保存一份短课件，并按第6节检查实际文件。

## 3. 打开课件并保存

1. 在刚才安装助手的浏览器中，正常登录学习通，打开一份PPT/PDF课件，等待页面显示。
2. 点击工具栏的“学习通课件助手”，或页面侧边的“课件助手”入口。
3. 在“课件”页核对文件名、页数和保存位置。只有发现多份候选资料时才需要选择。
4. 点击 **保存PDF** 或 **保存原文件**，等待完成。
5. 指定目录方式应显示 **已保存并校验**；浏览器下载方式应显示 **浏览器已确认下载完成**。到实际目录打开文件，核对首尾页、页数、顺序及小字或公式。

如果页内小窗停在“助手暂未加载完成”，点击 **独立小窗打开**。出现“课件 / 设置”且底部显示 `v0.4.3` 后继续操作。

图片合成的PDF可以离线阅读和批注，不能恢复可编辑PPT、动画或原始矢量图。“保存原文件”只适用于页面上可以正常获取的文件入口。

## 4. 选择保存位置

在助手的 **设置** 页选择保存方式：

| 保存方式 | 用法 |
| --- | --- |
| 浏览器下载文件夹 | 使用当前浏览器的下载位置；完成后可点击“打开所在文件夹” |
| 每次选择保存位置 | 每次弹出浏览器原生保存对话框，由你确定实际位置 |
| 指定文件夹 | 选择并授权一个专用文件夹，以后按该设置保存 |

### 指定文件夹

1. 选择“指定文件夹”，点击 **选择文件夹**。助手会打开普通的授权标签页。
2. 在系统选择器中选定目录，例如桌面上的“课程文件”，并允许保存。
3. 看到“文件夹已设置好”后，点击 **返回课件助手**，确认助手显示所选文件夹及“已授权”。授权页会保持打开。
4. 回到“课件”页保存，完成后在所选目录查看实际文件。

助手不会更改浏览器的全局下载位置。授权只属于当前浏览器配置，不能从Edge自动转移到Chrome。重启或权限变化后可能需要重新授权；记住文件夹不代表永久权限。

### 按课程整理

“按课程分文件夹”默认开启。假设选择的根目录叫“课程文件”：

| 设置 | 实际位置示例 |
| --- | --- |
| 指定文件夹，开启课程分组 | `课程文件/概率论/第一章.pdf` |
| 指定文件夹，关闭课程分组 | `课程文件/第一章.pdf` |
| 浏览器下载，开启课程分组 | `浏览器下载目录/学习通课件/概率论/第一章.pdf` |
| 浏览器下载，关闭课程分组 | `浏览器下载目录/学习通课件/第一章.pdf` |

课程文件夹名称按课程分别记忆，当前文件名只作用于这份课件。无法识别课程时可以手动填写；指定目录且开启分组时，需要填写课程名或关闭分组。

同名文件会另存副本，请以完成后显示的实际文件名为准。只想临时换一个位置时，点击 **本次另存为**，不会修改长期保存偏好。

指定目录写入后会读回核对大小和内容校验值，成功后才确认保存。它不出现在浏览器下载列表中，也不提供“打开所在文件夹”按钮，请直接到你选的目录查看。

直接点击学习通网站自己的下载链接，由网站和浏览器处理，不受助手设置控制。

## 5. 更新已有扩展

0.4.3正式发布沿用原有程序，只更新说明与支持状态；已安装0.4.3的用户无需重新安装。

更新程序版本时：

1. 等当前保存任务结束，下载并解压新版ZIP。
2. 备份原扩展程序文件夹，再把新文件复制到原位置，替换对应程序文件。保留原目录位置，不必卸载扩展。
3. 打开你安装助手的浏览器扩展管理页：Edge为 `edge://extensions`，Chrome为 `chrome://extensions`。
4. 找到“学习通课件助手”，点击 **刷新 / 重新加载**。
5. 关闭旧独立小窗，刷新原课件页，再次打开助手，检查底部版本号与保存位置。目录权限失效时按提示重新授权。

仅点击“重新识别”不会更新已经加载的扩展程序。重新加载扩展或刷新来源页会停止当前任务，请先等保存结束。

## 6. 保存后检查与常见问题

### 第一次使用检查

- 扩展列表与助手底部版本是否正确？
- 文件名、页数是否与当前课件一致？
- 实际PDF能否打开，首尾页、页面顺序、小字或公式是否正常？
- 保存目录是否正确，有没有缺页或其他失败提示？

页数来自“阅读器列表”时，工具会标明整份完整性尚未确认。浏览器下载完成或磁盘写入校验通过，也不自动证明网站提供了整份课件。

### 小窗无法打开

使用最新版安装包，在当前浏览器的扩展管理页重新加载并刷新课件。页内小窗仍超时可点击“独立小窗打开”；独立窗口也无法加载时，按窗口提示重试并记录错误文字。无需反复尝试F12排查。

### 目录需要授权或写入失败

在设置里点击“重新授权”，到授权页选择“继续使用这个文件夹”并允许访问。目录移动或失效时重新选择；磁盘空间不足时先腾出空间。同一任务可保留已获取图片后重试，失败时不会自动改存别处。

### 某些页面失败

恢复网络或学习通登录后重试。仍有失败页时不会将部分内容冒充完整PDF。原课件没有变化时，补存只重新获取失败页；来源已变化时需要重新识别。

### 保存完成但找不到文件

指定目录方式去所选文件夹和课程子目录查找，重名可能带编号。浏览器下载或“本次另存为”以下载列表和你在对话框里选定的位置为准。

### PDF不能选择文字

普通图片PDF可以阅读、批注，不能选择图片中的文字。可选“文字优先（本机OCR · 试验）”功能需要单独准备[本机OCR组件](https://github.com/Atetra2007/chaoxing-study-helper/blob/main/docs/本地OCR使用说明.md)，默认关闭；公式、插图和识别不确定的页面会保留图片。普通保存不需要安装OCR。

### 收起、暂停或关闭页面

收起助手或关闭独立助手窗口不主动取消任务，保留原课件页即可。暂停用于图片获取阶段；PDF合并、原文件获取和目录写入阶段可取消。刷新、导航或关闭原课件、重启浏览器、重新加载扩展后，需要重新识别，不支持跨重启续传。

当前限制为500页、单页25MiB、总图片250MiB。来源图片和生成中的PDF会暂存在浏览器私有本机存储，磁盘需有足够空间。临时存储不可用时明确停止，不回退到整本教材占用内存的旧路线。

## 7. 验证状态与反馈

0.4.3已有真实Edge目录授权、返回助手和按课程保存成功记录，实际28页PDF已完成独立解析及渲染检查，但未与网站来源逐页独立比对。原页内小窗根因、重启后的目录授权恢复、真实同名保护等仍有待验证项。

2026-10-16，用户确认Chrome实际使用验收通过，0.4.3正式支持Chrome与Edge。Chrome结论来自用户验收反馈，本次没有新增对其输出文件的独立逐页比对；OCR及其他未单独记录的场景仍按各自证据判断。详细记录见[开发进度](https://github.com/Atetra2007/chaoxing-study-helper/blob/main/docs/进度.md)及[0.4.3修复记录](https://github.com/Atetra2007/chaoxing-study-helper/blob/main/docs/修复记录-0.4.3.md)。

遇到问题请[提交反馈](https://github.com/Atetra2007/chaoxing-study-helper/issues/new/choose)，说明扩展版本、浏览器名称与版本、操作步骤和提示文字。不要上传账号密码、Cookie、OCR连接文件或带登录参数的链接；截图请遮挡个人和课程信息。

课件在本机处理，依赖随扩展打包；网站访问、下载、后台处理和本地存储权限的用途见[隐私与权限说明](https://github.com/Atetra2007/chaoxing-study-helper/blob/main/PRIVACY.md)。

## 8. 开发者构建与更新

普通用户不需要执行命令。开发者可在项目中运行 `pnpm package`，生成完整扩展和中性名称的ZIP。

`pnpm update:local` 会构建、备份并校验固定安装目录。首次可用 `pnpm update:local --target outputs/原安装目录名` 指定目录，此后记住该位置；更新文件后仍需在对应浏览器手动重新加载。备份位于 `work/extension-backups/`，还原时只恢复扩展程序文件，不动课件和笔记。

安装步骤参考：[Edge官方说明](https://learn.microsoft.com/en-us/microsoft-edge/extensions/getting-started/extension-sideloading)、[Chrome官方说明](https://developer.chrome.com/docs/extensions/get-started/tutorial/hello-world)。
