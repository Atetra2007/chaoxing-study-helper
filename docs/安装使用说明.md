# 学习通课件助手 0.1.5：安装使用说明

## 获取与更新

当前0.1.5为本地开发构建，输出为 `outputs/chaoxing-study-helper-0.1.5`。发布到GitHub后，也可从成功的Actions运行下载构建；尚未发布时不要将旧Artifacts当作新版。

推荐在项目目录运行 `pnpm update:local`：自动构建、检查版本和源码一致性，备份旧文件，再逐项校验更新文件。首次默认安装目录为 `outputs/installed`；已安装用户首次指定 `pnpm update:local --target outputs/原安装目录名`，此后自动记住该目录，不改变Edge加载路径。目标仅允许本项目outputs的直接子目录，不接受其他扩展目录或链接目录。

旧文件备份保存在 `work/extension-backups/`，具体路径由命令输出。需要恢复时，将该次备份中的文件复制回原安装目录，再重新加载扩展；不要删除已有课件或批注。更新文件不会自动替你重新加载Edge。

更新已安装扩展时，将新构建目录中的文件复制到原安装目录，保留原目录位置。然后：

1. 在 Edge 手动打开 `edge://extensions`，找到“学习通课件助手”，点击卡片上的刷新/重新加载按钮。
2. 关闭原来的助手页面，回到课件，再点击扩展图标打开助手。
3. 确认助手顶部显示 `v0.1.5`，点击“保存为 PDF”。版本直接读取运行中扩展的manifest。

无需卸载或再次加载目录。普通保存的权限不变；启用本机OCR时会单独申请访问本机组件的可选权限。本机最早安装目录是 `D:\projects\chaoxing\outputs\chaoxing-study-helper-0.1.0`，目录名可以保留，实际版本以助手和manifest为准。

## 首次安装

1. 在 Edge 地址栏中手动输入 `edge://extensions`，按回车。
2. 打开“开发人员模式”（不同版本可能称“开发者模式”）。
3. 点击“加载解压缩的扩展”。
4. 选择直接包含 `manifest.json` 的固定安装目录，例如运行更新脚本后的 `outputs/installed`。
5. 确认扩展列表中出现“学习通课件助手 0.1.5”。

请选择直接包含 `manifest.json` 的目录，而不是项目根目录或 ZIP 文件。

如果在其他电脑使用，先把 ZIP 解压到一个固定目录，再按以上步骤加载其中包含 `manifest.json` 的文件夹。加载后不要移动该文件夹。

## 使用

1. 在 Edge 正常登录学习通，打开需要保存的 PPT/PDF 课件，等待页面显示。
2. 点击工具栏的扩展菜单，选择“学习通课件助手”。可以将它固定到工具栏方便下次使用。
3. 助手会打开一个独立的保存页面，自动识别原课件标签页。
4. 如果识别出多份内容，先选择要保存的一份。可见的原文件链接会优先列出。
5. 填写课程文件夹，调整文件名称，点击“保存为 PDF”或“下载原文件”。
6. 等待显示“已保存到电脑”，再打开文件夹。默认路径是浏览器下载目录下的 `学习通课件/课程名称/文件名称`。

勾选“保存时让我选择位置”，可以使用浏览器保存对话框指定位置。重名文件会自动另存，不覆盖旧资料或个人笔记。

## 保存进度

“图片页画质”默认均衡压缩，保留来源分辨率与颜色；精细公式或需要保留来源像素时选择“原画质”。已有JPEG不重复有损压缩，无法有效缩小的页面保留来源图片。压缩比例因教材而异。

“文字优先（本机OCR · 试验）”默认关闭。勾选后，可信纯文字页尽量按原位置生成文字；插图、表格、公式及不确定页自动保留图片。需要先连接本机组件，具体步骤见[本地OCR使用说明](本地OCR使用说明.md)。当前电脑已安装组件，但新版扩展首次授权和连接仍需手动操作。

“页数依据”区分阅读器明确显示的总页数与已适配阅读器列出的页面。后者可以保存列出的页面，但仍显示“整份完整性未确认”；浏览器下载完成不自动证明课件完整。

同类失败合并显示原因和页码范围，页面格仍保留每页状态。“诊断信息（已脱敏）”可以复制版本、页数依据、失败页码和耗时；不含标题、课程、路径、账号、资源链接和原始错误。复制失败时可在文本框按Ctrl+C。可用时记录的JS堆占用仅是观察值，不代表浏览器峰值内存。

- 灰色：等待获取。
- 蓝色：正在获取。
- 绿色：已经获取。
- 红色：多次尝试仍失败，需要重试。

只要还有失败页，工具就不会把不完整的资料保存为完整PDF。“重试失败页面”会保留成功页，只补存失败页。

点击暂停后，已经发出的请求会完成；后续请求停止。点击继续可恢复。暂停适用于图片获取阶段，PDF合并和原文件下载阶段可以取消。

保存时可以切换窗口，但请保持保存页面和原课件标签页打开，勿在原标签页切换到另一份课件。电脑休眠会暂停工作。关闭或刷新保存页面后，需重新开始；当前版本未提供浏览器重启后的断点续存。

## 权限与本地数据

- `activeTab`、`scripting`：在用户发起操作时读取课件页面及嵌套阅读器。
- `https://*.chaoxing.com/*`：读取学习通课程页面和文档阅读器。
- `https://*.cldisk.com/*`：获取当前课件引用的页面图片或文件。
- `downloads`：保存文件并确认浏览器下载完成，支持打开所在文件夹。
- `storage`：在本机记住课程名称与最近60条保存记录。

不需要输入密码，不读取Cookie内容，不上传课件到第三方处理服务。依赖的PDF库已打包，不在线加载脚本。

## 常见问题

**没有识别到课件**：确认打开的是具体文档阅读器，等待加载后点击“重新识别”；确认扩展有访问学习通的权限。当前版本对未知阅读器会停止并提示，不猜测未显示的总页数。

**课程“资料”里的WPS教材**：保持教材弹窗打开，从同一个课程标签页点击助手。对于已验证的页面，助手会在需要时切换到教材自带的普通预览，并使用教材文件名。若提示普通预览未加载，点击教材右下角的预览切换按钮，等待页面出现后回助手重新识别。只有WPS画布且没有可用普通预览的资料仍暂不支持。

**某些页失败**：检查网络后重试。若显示访问被拒绝，回学习通恢复登录并重新打开资料，再点击“重新识别”。

**原文件入口失败**：只支持页面可见且指向支持格式的正常链接。需要跳转的下载入口、特殊响应或未支持的域名可能暂不可用；可以选择同一份资料的页面PDF（若已识别）。

**PDF不能选择文字**：普通图片页可以批注，但不能选择文字。文字优先模式中，只有成功转换的文字页可选中文字；识别不确定而保留的图片页仍不可选择。原始可编辑PPT和矢量图不会从图片中恢复出来。

**保存完成但没有在预期文件夹中找到**：打开浏览器下载列表查看实际位置；如果选择过“另存为”，以手动选择的位置为准。
