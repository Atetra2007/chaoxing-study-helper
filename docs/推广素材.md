# 学习通课件助手推广素材

适用版本：0.4.3正式版。以下文字可复制到你自己的校园社区或社交账号；发布前确认该社区允许分享工具。

## 简短介绍

学习通课件助手：将你已打开的学习通课件保存到电脑，按课程整理，方便离线阅读和批注。免费开源，支持Windows上的Chrome与Edge，普通保存不需要Python或OCR服务。

## 分享文案

我做了一个“学习通课件助手”，想解决复习时课件不好整理、离线批注不方便的问题。

正常打开课件后，可以保存可获取的原文件，或将分页图片合成为PDF，并按课程放进指定文件夹。当前正式版0.4.3支持Windows上的Chrome与Edge，两种浏览器使用同一份安装包。

下载、安装教程和问题反馈入口都在项目首页。首次使用可以先保存一份自己有权保存的短课件，检查页数和清晰度。它是非官方工具，部分阅读器还不支持；图片PDF不能恢复为可编辑PPT。
