# 学习通课件助手推广素材

适用版本：0.4.3公开试用版。以下文字可复制到你自己的校园社区或社交账号；发布前确认该社区允许分享工具。

## 简短介绍

学习通课件助手：将你已打开的学习通课件保存到电脑，按课程整理，方便离线阅读和批注。当前支持Windows + Edge，普通保存不需要Python或OCR服务。

## 同学试用邀请

我做了一个“学习通课件助手”，想解决复习时课件不好整理、离线批注不方便的问题。

正常打开课件后，可以保存可获取的原文件，或将分页图片合成为PDF，并按课程放进指定文件夹。当前是0.4.3试用版，适用于Windows + Edge。

欢迎先用一份自己有权保存的短课件试试，尤其想听听“安装有没有卡住、保存后能不能找到文件、页数和清晰度怎么样”。它是非官方工具，部分阅读器还不支持；图片PDF不能恢复为可编辑PPT。
