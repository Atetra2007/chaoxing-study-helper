## 更新方式

1. 在GitHub Issues或本项目任务中说明一个具体问题及复现步骤。
2. 在独立分支中修改，补充与问题有关的验证，更新CHANGELOG。
3. 提交后由GitHub Actions执行测试与构建。自动检查通过后，仍按需要进行真实Edge验证。
4. 合并后从Actions的Artifacts下载新构建，或在本地执行 `git pull --ff-only`、`pnpm install --frozen-lockfile`、`pnpm run build`。

GitHub保存的是工具源码和开发记录。课件、个人笔记以及浏览器登录信息保持在本地。
