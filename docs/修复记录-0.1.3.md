# 0.1.3：课程资料弹窗中的教材无法识别

日期：2026-09-15

## 实际页面

用户从课程“资料”中打开教材弹窗。顶层仍为 `/mooc2-ans/mycourse/stu`，并未进入旧版支持的 `studentstudy` 页面。内层资源页为 `/ananas/modules/pdf/mooc2-resource-index.html`，默认展示WPS阅读器。

普通阅读器和WPS阅读器使用同一个文件标识。通过平台可见的右下角切换控件，能切换到 `screen/v2` 图片阅读器：共310页、页码1至310连续、310张PNG全部已加载，尺寸均为1023×1425，图片均来自已允许的cldisk域名。WPS页码框显示1/310，页数一致。资料弹窗显示的文件名为“大学物理学（上册）教材.pdf”。

本记录不保存文件标识、账号信息、签名参数或资源链接。截图和课件文件不提交GitHub。

## 原因与修复

1. 旧版初始化只筛选章节和直接图片阅读器URL，丢弃了实际课程资料标签页。新增来源选择模块，保留用户发起操作的受支持标签页，并识别课程资料入口。
2. WPS模式不能直接按旧图片规则识别。新增受限切换函数，仅在没有可用候选时，核对包装页、两个阅读器的同文件关联、按钮可见性，再点击平台已有的普通预览控件。
3. 切换后最多等待8秒，只接受同一文件的图片阅读器；关闭、重新加载、身份变化、超时或多个入口均停止，不选取其他教材充数。
4. 从可见资料弹窗读取文件名，沿包装页和图片阅读器的明确关联传递，避免使用课程名称。

无需新增浏览器权限。没有可用普通预览的WPS文档仍暂不支持；未提取画布或猜测下载接口。

## 验证

- 47/47自动测试通过，包含课程资料来源、保留明确来源、关闭来源、弹窗标题传递、相同文件匹配、隐藏/禁用控件、不同文件、切换超时与无响应。
- 实际浏览器确认官方预览控件可正反切换，文件关联保持一致；普通预览310页的连续性、图片尺寸、加载状态和资源域名均已核对。
- 安装后完整保存和导出PDF的逐页核验仍待用户重新加载后执行。浏览器工具禁止访问扩展内部页面，不能替用户点击扩展管理页及保存界面。
