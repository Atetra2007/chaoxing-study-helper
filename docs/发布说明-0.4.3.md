# 学习通课件助手 0.4.3 正式版

将你已打开的学习通课件保存到电脑，按课程整理，方便离线阅读和批注。支持Windows上的Google Chrome与Microsoft Edge，两种浏览器共用一个安装包。最低版本要求116，建议使用最新版。

## 下载与安装

普通用户下载 **[chaoxing-study-helper-0.4.3.zip](https://github.com/Atetra2007/chaoxing-study-helper/releases/download/v0.4.3/chaoxing-study-helper-0.4.3.zip)**，解压到固定目录，选择对应浏览器的安装入口：

| 浏览器 | 地址栏输入 | 操作 |
| --- | --- | --- |
| Edge | `edge://extensions` | 开启“开发人员模式”→“加载解压缩的扩展” |
| Chrome | `chrome://extensions` | 开启“开发者模式”→“加载已解压的扩展程序” |

选择直接包含 `manifest.json` 的文件夹。两种浏览器需要分别安装、登录学习通和授权保存目录；首次使用请核对实际保存文件。

普通保存无需Python或Node.js。GitHub自动提供的 `Source code` 是开发源码，`promo.zip` 是推广素材，都不是安装包。`SHA256SUMS.txt` 用于核对文件下载是否完整。

2026-10-16正式发布：用户已确认Chrome验收通过，0.4.3由预发布转为正式发布。安装教程和支持说明同步更新，程序、权限和版本号未变，已安装0.4.3的用户无需重新安装。安装包统一使用中性名称，请使用本页下载入口。

## 功能

- 优先保存可获取的原文件，分页图片按顺序合成PDF。
- 页内助手与独立小窗后备入口，支持暂停、继续和失败补存。
- 指定保存文件夹、按课程整理、均衡/原画质选择。
- 指定目录写入后读回核对大小与SHA-256；已知缺页或冲突时阻止导出。
- 可选本机OCR试验功能，默认关闭，需单独准备本机组件。

## 验证与已知限制

发布前已运行315项扩展自动测试和4项本机OCR组件测试。0.4.3已有真实Edge目录授权、返回助手及按课程保存的用户确认；实际28页PDF可正常解析与渲染。该文件尚未与网站来源逐页独立比对。

Chrome实际使用验收由用户确认通过。本次发布依据该确认更新支持状态；未新增对Chrome输出文件的独立解析或逐页比对记录，未据此将OCR、重启权限恢复等未单独记录的场景全部标为通过。

部分实际页面的页内小窗会超时，可选择“独立小窗打开”。历史版本发生过目录选择后Edge关闭，0.4.3调整后的流程已成功，但此前崩溃唯一根因仍未确定。重启后的目录授权恢复、真实同名保护及其他未覆盖场景仍待验证。

保存时保留原课件页；刷新、导航或关闭来源页、重启浏览器后不能续传。macOS及未知阅读器尚未完成兼容验收。图片PDF不能恢复可编辑PPT或动画。
