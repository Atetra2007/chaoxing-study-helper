# 学习通课件助手0.4.3公开试用版

将你已打开的学习通课件保存到电脑，按课程整理，方便离线阅读和批注。目标环境为Windows + Microsoft Edge 116及以上，建议使用最新版Edge。

## 下载与安装

普通用户下载 **`chaoxing-study-helper-0.4.3-edge.zip`**，解压到固定目录。在Edge地址栏输入 `edge://extensions`，打开“开发人员模式”→“加载解压缩的扩展”，选择直接包含 `manifest.json` 的目录。

普通保存无需Python或Node.js。GitHub自动提供的 `Source code` 是开发源码，不能直接加载为扩展。`SHA256SUMS.txt` 用于核对文件下载是否完整。

[完整安装教程](https://github.com/Atetra2007/chaoxing-study-helper/blob/main/docs/安装使用说明.md) · [反馈问题](https://github.com/Atetra2007/chaoxing-study-helper/issues/new/choose)

## 功能

- 优先保存可获取的原文件，分页图片按顺序合成PDF。
- 页内助手与独立小窗后备入口，支持暂停、继续和失败补存。
- 指定保存文件夹、按课程整理、均衡/原画质选择。
- 指定目录写入后读回核对大小与SHA-256；已知缺页或冲突时阻止导出。
- 可选本机OCR试验功能，默认关闭，需单独准备本机组件。

## 验证与已知限制

发布前已运行315项扩展自动测试和4项本机OCR组件测试。0.4.3已有真实Edge目录授权、返回助手及按课程保存的用户确认；实际28页PDF可正常解析与渲染。该文件尚未与网站来源逐页独立比对。

部分实际页面的页内小窗会超时，可选择“独立小窗打开”。历史版本发生过目录选择后Edge关闭，0.4.3调整后的流程已成功，但此前崩溃唯一根因仍未确定。重启后的目录授权恢复、真实同名保护及其他未覆盖场景仍待验证。

保存时保留原课件页；刷新、导航或关闭来源页、重启浏览器后不能续传。未知阅读器不保证支持。Chrome与其他系统尚未完成实机验收。图片PDF不能恢复可编辑PPT或动画。

演示素材均使用合成课件和模拟浏览器接口，不包含私人课程资料，不代表真实扩展验收。
