# 使用与反馈清单

建议首次使用时保存一份自己有权保存的短课件。当前正式版为0.4.3，支持Windows上的Chrome与Edge。

## 完成一次保存

- 能否按照[安装教程](https://github.com/Atetra2007/chaoxing-study-helper/blob/main/docs/安装使用说明.md)独立安装，并在扩展列表看到0.4.3？
- 打开课件后，是否能打开助手并看到正确文件名与页数？若页内小窗超时，独立小窗能否打开？
- 保存后，能否找到实际文件并打开？
- 与原阅读器核对：总页数、第一页、最后一页、页面顺序，以及至少一页小字或公式是否正常？
- 是否出现缺页提示、浏览器关闭、目录授权失败、覆盖旧文件或其他异常？

请保留原始课件和笔记。不要为了测试同名保护而使用唯一的一份重要文件。

## 可直接填写

```text
扩展版本：0.4.3
系统、浏览器名称与版本：
是否独立安装成功：
小窗是否打开（页内 / 独立小窗）：
资料类型（原文件 / 分页图片PDF）：
来源页数 / 保存后页数：
实际文件能否打开、顺序和清晰度是否正常：
遇到的问题、提示文字及操作步骤：
最希望改进的一点：
```

通过[GitHub问题反馈](https://github.com/Atetra2007/chaoxing-study-helper/issues/new/choose)提交即可。反馈中不需要真实课件、姓名、学号、账号或资源链接；截图请先遮挡这些内容。
