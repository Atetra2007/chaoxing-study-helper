# 学习通课件助手

将自己在Edge中打开的学习通PPT/PDF课件保存到电脑，便于离线阅读和批注。

当前版本：**0.1.3，开发验证阶段**。支持章节、课程资料弹窗及已适配阅读器的页面图片PDF；真实Edge完整保存仍待验证，不承诺兼容所有课件。

## 已有功能

- 按需识别当前课件和嵌套阅读器，优先列出可见原文件入口。
- 课程资料弹窗中的WPS教材可使用平台自带的普通预览；在需要时切换并核对是同一文件。
- 按页码合成PDF；遇到已知缺页、页数冲突或加载失败时停止导出。
- 显示进度、暂停/继续、失败页补存、取消保存。
- 按课程文件夹归档，同名自动另存；下载完成后提示成功。

页面图片PDF保留原貌，可批注，但没有OCR文字层，也不能恢复可编辑PPT或动画。

## 安装与使用

1. 在仓库的 **Actions → Test and build** 中打开一次成功运行，从 **Artifacts** 下载构建；也可按下文在本地构建。
2. 解压到固定目录。在Edge中手动打开 `edge://extensions`，启用开发人员模式，选择“加载解压缩的扩展”，加载直接包含 `manifest.json` 的目录。
3. 正常登录学习通，打开需要保存的课件，点击“学习通课件助手”。
4. 确认资料、课程文件夹和文件名，点击“保存为 PDF”或“下载原文件”。

保存时保留助手页和原课件页。默认输出到浏览器下载目录的 `学习通课件/课程名称/文件名`。详细步骤及更新方式见[安装使用说明](docs/安装使用说明.md)。

## 本地开发

需要Node.js 24和pnpm 11.19.0。扩展运行本身不需要Node.js、Python或本地服务。

```sh
git clone https://github.com/Atetra2007/chaoxing-study-helper.git
cd chaoxing-study-helper
pnpm install --frozen-lockfile
pnpm test
pnpm run build
```

构建输出为 `outputs/chaoxing-study-helper-0.1.3/`，文件夹版本跟随manifest。依赖的PDF库随扩展打包，不在线加载脚本。

```sh
pnpm run preview
```

打开 `http://127.0.0.1:4178/?source=42`，使用31页**合成测试图片**体验完整界面，无需账号或个人课件。原生浏览器请求检查位于 `http://127.0.0.1:4178/tests/browser-native-fetch.html`。这些页面模拟扩展接口，不能代替安装后的权限与真实下载验证。

GitHub Actions在推送main或提交PR时执行锁定依赖安装、测试与构建；构建产物保留14天。新机器可直接从仓库重建。

## 验证与当前限制

- 0.1.0首次实际保存发现fetch调用错误，0.1.1修复并通过原生浏览器复现检查。
- 0.1.2修复“可见总页数大于已加载页码”的不完整导出风险，并加入回归测试。
- 0.1.3在真实课程资料弹窗验证了WPS与普通预览的同文件关联，普通预览提供完整310页图片；不代表所有WPS阅读器均可保存。
- 原始31页样本曾通过本地图片合并、逐页像素核对和公式页检查；该证据与正式扩展端到端验证分开记录。
- 未知阅读器暂不支持；无显式总页数时，仅使用已适配阅读器的页列表，界面明确称为“阅读器列出”的页数。
- 当前限制为500页、单页25MB、总图片250MB。关闭/刷新助手或重启浏览器会丢失本次任务缓存。
